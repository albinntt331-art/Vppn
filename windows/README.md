# Albin-vpn Desktop для Windows (PySide6 + Xray-core + sing-box)

Десктопный клиент в стиле Google Pixel Material 3 Expressive (фиолетовый акцент по умолчанию + 5 палитр, тёмная/светлая тема, анимированный ореол кнопки подключения и живой график трафика).

## Сборка в один `.exe` на Windows
1. Установите Python 3.11+ (*Add Python to PATH*).
2. Запустите **`build_exe.bat`** — скрипт сам установит зависимости, скачает `xray.exe` и `sing-box.exe` и соберёт **`dist/Albin-vpn.exe`**.
