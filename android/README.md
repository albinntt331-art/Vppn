# Albin-vpn Android (Kotlin + Jetpack Compose + Material 3 Expressive)

Двухъядерный Android VPN-клиент в стиле Google Pixel (Material You), совмещающий возможности **Happ / v2RayTun (Xray-core)** и **Hiddify (sing-box)** с фиолетовым акцентом по умолчанию, анимированным световым ореолом кнопки подключения и живыми графиками трафика.

## Сборка APK через GitHub Actions
1. Загрузите содержимое этой папки в приватный репозиторий GitHub.
2. Откройте **Actions -> Build Albin-vpn APK -> Run workflow**.
3. Скачайте готовый `.apk` из раздела **Artifacts**.
